# 🚀 Personal Portfolio - Muhammad Safeer

A responsive personal portfolio website showcasing my work as a **DevOps and DevSecOps Engineer**. It features a dark glassmorphism design, smooth animations, filterable projects, and a contact form.

## 🎯 About Me

I'm Muhammad Safeer, a DevOps and DevSecOps engineer based in Lahore, Pakistan. I started in server administration and IT support, and today I build secure CI/CD pipelines, automate infrastructure, and deploy containerized applications in the cloud. I hold a BS in Information Technology from Government College University Faisalabad, along with Huawei HCIA (Cloud Computing and Security), Microsoft SC-900, and ISACA Cybersecurity Fundamentals certifications.

## ✨ Features

- **Glassmorphism UI** - Glass-style cards with backdrop blur on a dark theme with yellow accents
- **Responsive Design** - Adapts to phones, tablets, and desktops
- **Typing Headline** - Animated hero text that cycles through my roles
- **Project Filters** - Filter projects by DevOps, Security, Infrastructure, and Data
- **Growth Timeline** - A short timeline of my education and career
- **Contact Form** - Visitors can send me a message directly from the site

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, or Edge)
- A text editor such as VS Code
- Git

### Quick Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/MSafeer07/portfolio.git
   cd portfolio
   ```

2. **Run it locally** (choose one)

   **Option A: Python HTTP server**
   ```bash
   python -m http.server 8000
   ```

   **Option B: PHP development server** (needed to test the contact form)
   ```bash
   php -S localhost:8000
   ```

   **Option C: VS Code Live Server**
   - Install the Live Server extension
   - Right-click `index.html` and choose "Open with Live Server"

3. **Open the site**
   ```
   http://localhost:8000
   ```

## 🔧 Customization

- **Content**: edit the sections in `index.html`
- **Photo**: replace `assets/img/safeer.jpg` with a square image
- **Colors and styles**: `assets/css/main.css`
- **Contact form**: set the recipient email in `contact.php`. GitHub Pages does not run PHP, so for a hosted version use a form service such as Formspree or Web3Forms.
