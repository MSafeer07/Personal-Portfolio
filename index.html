About Me

🚀 From Server Admin to DevSecOps Engineer

My career started in server administration, keeping Linux and Windows servers patched, backed up, and monitored. Working with real infrastructure every day taught me how systems behave under pressure, and that hands-on foundation still shapes how I build today. Each pipeline and deployment I work on is about making systems more reliable and more secure.

I hold a BS in Information Technology. with certifications from Huawei (HCIA Cloud Computing and Security), Microsoft (SC-900), and ISACA. I specialize in DevOps automation and CI/CD pipelines with security built in, and I have hands-on experience with Docker, Kubernetes, Jenkins, Terraform, and Ansible, including a Fortinet SSL VPN client packaged in Docker and my thesis on containerizing web applications.

Beyond my day-to-day work, I keep learning new tools and practicing what I learn in real projects, from email delivery infrastructure on a Linux VPS to live reporting in Power BI. I believe in continuous learning and staying current with trends in cloud, DevOps, and security.

💡 What drives me? Security works best when it is built in from the start, automation beats repetition, and every system I run should be easy to monitor, understand, and fix.
